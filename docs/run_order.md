# Run order

Suggested order for the public analysis pieces:

1. install the Python dependencies from `analysis/requirements.txt`
2. inspect `analysis/code_map.md`
3. review the selected scripts in `analysis/scripts/`
4. read the result figures in `results/figures/`
5. open the final thesis PDF in `thesis/final_report.pdf`

The full private pipeline includes extra extraction and intermediate steps that are not part of this public repo.
