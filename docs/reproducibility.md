# Reproducibility notes

This repository is a public support repo for the thesis results.

## Reproducible pieces

- the final thesis PDF
- selected analysis scripts
- selected figures and summaries
- dependency list for the Python analysis step

## Not included

- raw student submissions
- private working notes
- LaTeX source files
- temporary or experimental outputs

## How the results were produced

1. clean and merge the submission data privately
2. compute the student-level features
3. build the clustering and profile outputs
4. generate the final figures and summary tables
5. export the final report PDF
